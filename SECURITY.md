# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately, not in a public issue: use
GitHub's Security Advisories "Report a vulnerability" button on this
repository (Security tab → "Report a vulnerability"). That opens a private
advisory visible only to the maintainer and you, and works for any public
GitHub repository without extra setup on our side.

Please do not open a public issue or pull request for a suspected
vulnerability.

## Supported versions

This project is pre-1.0 (beta). Only `main` and the latest release are
supported; there are no maintained older release branches.

## Independent review

This project has not yet had an independent outside security review. Code
so far has been reviewed by AI agents and the maintainer, not by an outside
security firm. Keep that in mind when deciding how much to trust it, and
please report suspected vulnerabilities privately rather than opening a
public issue.
